# ContourPDF

Консольное приложение для добавления цветных контуров вокруг фигур в PDF файлах. Идеально подходит для обработки разверток для паперкрафта, выкроек и других графических материалов.

## Возможности

- ✅ Добавление цветных контуров вокруг фигур (цвет контура соответствует цвету фигуры)
- ✅ Настраиваемая ширина контура в сантиметрах
- ✅ Опциональное зеркалирование изображений по вертикали
- ✅ Многопоточная обработка для ускорения работы
- ✅ Детальные прогресс-бары для отслеживания процесса
- ✅ Поддержка PDF файлов любого размера
- ✅ Конвертация PDF в формат A5 для печати

## Требования

- Python 3.7+
- Установленные библиотеки:
  - PyMuPDF (fitz)
  - Pillow (PIL)
  - NumPy
  - SciPy
  - tqdm

## Использование

### Базовое использование

```bash
python3 add_contours.py input.pdf output.pdf
```

### С настройкой ширины контура

```bash
python3 add_contours.py input.pdf output.pdf --width 0.5
```

### С зеркалированием

```bash
python3 add_contours.py input.pdf output.pdf --mirror
```

### С настройкой количества потоков

```bash
python3 add_contours.py input.pdf output.pdf --workers 4
```

### Все параметры вместе

```bash
python3 add_contours.py input.pdf output.pdf --width 0.3 --mirror --workers 8
```

## Конвертация в формат A5

Скрипт `convert_to_a5.py` позволяет конвертировать PDF файлы в формат A5 (148 x 210 мм) для печати.

### Базовое использование

```bash
python3 convert_to_a5.py input.pdf output.pdf
```

### Режимы подгонки содержимого

```bash
# Вписать содержимое в A5 (сохраняет пропорции, могут быть поля)
python3 convert_to_a5.py input.pdf output.pdf --fit fit

# Заполнить весь формат A5 (сохраняет пропорции, может обрезаться)
python3 convert_to_a5.py input.pdf output.pdf --fit fill

# Растянуть содержимое на весь формат A5 (может исказить пропорции)
python3 convert_to_a5.py input.pdf output.pdf --fit stretch
```

### Настройка качества

```bash
# Высокое качество для печати (300 DPI - по умолчанию)
python3 convert_to_a5.py input.pdf output.pdf --dpi 300

# Максимальное качество (600 DPI - для очень детальных изображений)
python3 convert_to_a5.py input.pdf output.pdf --dpi 600

# Среднее качество для экрана (150-200 DPI)
python3 convert_to_a5.py input.pdf output.pdf --dpi 150
```

### Параметры convert_to_a5.py

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `input` | Путь к входному PDF файлу (обязательный) | - |
| `output` | Путь к выходному PDF файлу (обязательный) | - |
| `--fit` | Режим подгонки: `fit`, `fill`, `stretch` | `fit` |
| `--dpi` | Разрешение для рендеринга в DPI | `300` |

## Параметры командной строки

| Параметр | Короткая форма | Описание | По умолчанию |
|----------|----------------|----------|--------------|
| `input` | - | Путь к входному PDF файлу (обязательный) | - |
| `output` | - | Путь к выходному PDF файлу (обязательный) | - |
| `--width` | `-w` | Ширина контура в сантиметрах | 0.25 |
| `--mirror` | `-m` | Зеркалировать изображения по вертикали (лево-право) | Выключено |
| `--workers` | `-j` | Количество потоков для обработки | Количество ядер CPU |

## Как это работает

1. **Извлечение изображений**: Приложение извлекает все изображения из PDF файла
2. **Определение цветных областей**: Находит цветные фигуры (исключая белый фон)
3. **Добавление контуров**: Создает контур вокруг каждой цветной фигуры, используя цвет самой фигуры
4. **Зеркалирование** (опционально): Отражает изображения по вертикали, если включено
5. **Сборка PDF**: Собирает обработанные изображения обратно в PDF файл

## Технические детали

- Использует морфологические операции для определения границ фигур
- Применяет distance transform для эффективного определения цвета контура
- Поддерживает параллельную обработку страниц для ускорения
- Автоматически рассчитывает ширину контура в пикселях на основе масштаба изображения

## Скрипты проекта

- `add_contours.py` - добавление цветных контуров вокруг фигур в PDF
- `convert_to_a5.py` - конвертация PDF в формат A5 для печати
- `analyze_pdf.py` - анализ структуры PDF файлов
- `analyze_pdf_detailed.py` - детальный анализ PDF с извлечением цветов

## Ограничения

- Работает только с растровыми изображениями в PDF (не с векторной графикой)
- Контуры добавляются только вокруг цветных фигур (белый фон игнорируется)
- Зеркалирование применяется ко всем изображениям на странице
- При конвертации в A5 используется растровый рендеринг с настраиваемым разрешением (по умолчанию 300 DPI для печати)
- Более высокое разрешение (600 DPI) дает лучшее качество, но увеличивает размер файла
